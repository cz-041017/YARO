YARO — You Only Run Once

面向机器视觉全链路的开发 harness：数据集体检、标注抽查、切分、训练计划、调优、部署验收，全部可回滚可追溯。

  • 在下方输入任务，或勾选 演示模式 看一条不花 token 的全链路运行（demo/dataset）。
  • 每次工具调用的证据（图像 / 表格 / 指标）都会落在产物库里，artifact:// 地址可追溯。
  • 右栏 时间线 支持 rewind / fork，回滚只移动指针，不删除历史。
  • 模型自报的分数一律不被采信：指标由 harness 的评估函数计算。
  • 默认不出网（egress=off）：原始图与密钥不出本机；真实模型调用需显式授权。
